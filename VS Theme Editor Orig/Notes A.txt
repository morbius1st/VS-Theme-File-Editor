process selecting theme

theme file types

theme types
A user theme with a fallback guid
B user theme without a fallback guid
C VS root theme A (e.g. Theme.Light.pkgdef)
D VS root theme B (e.g. Shell.Light.pkgdef)
E VS builtin theme (e.g. bubblegum.pkgdef)
	
theme styles

A light
B dark
C high contrast


determine theme type

* SelectVsData returns: VsId, ThemeSource, & ThemeStyle
	* cases for ThemeSource & ThemeStyle
		* A TSRC_USER + TSTY_TBD
		* B TSRC_UKN + TSTY_UKN
		* C TSRC_VS_* + TSTY_ {LIGHT / DARK / HC}
		* D TSRC_BUILTIN + TSTY_TBD
		
* process A
	* read header & get fallback
	* exists
		* with VsId, scan to determine VsThemeInfo 
			from VsDataList which provides the root theme files (currently 2)
			which get merged
	* does not exist
		* select Light VsThemeInfo to provide the root theme files (currently 2)
		
* process B
	* ignore
	
* process C
	* create a VsThemeInfo file with the other root theme files
	
* process D
	* with VsId, parse the Theme Reg File to determine the fallback
	* with VsId, scan to determine VsThemeInfo from the VsDataList, etc.
	





basic process

* user selects a theme file (this is the base theme)

* determine theme file type (use UKN when user theme)

* read the theme files fallback guid

* based on the above, determine the style, source, and description

* based on the style and source, determine the fallback theme(s)

* read each fallback theme file (or use the version already read)

* merge the fallback themes into the base theme file to create the working theme

* present the working theme
